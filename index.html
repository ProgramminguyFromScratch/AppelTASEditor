What is this?

                    

                        The Appel TAS Editor lets you record, edit, and replay
                        frame-perfect inputs for the game Appel.
                        Write inputs in the Frame Inputs tab,
                        watch them play out on the canvas, scrub the timeline, and use
                        Randy to automatically find routes. This is the browser version; the Brute Force Solver and the native Randy engine are in the full download (see below).
                    

                    

                        The layout is split into a left panel (game canvas + player state)
                        and a right panel (level code, inputs, Randy, replay).
                        A timeline runs along the bottom showing every frame's key state.
                    

                


                

                    
Getting Started

                    

                        

                            1. Load a level
                            Paste a level code into the Level Code field at the top-right and press Enter.
                        

                        

                            2. Write inputs
                            Switch to the Frame Inputs tab and type your input sequence (see syntax below).
                        

                        

                            3. Playback
                            Press Q to restart from frame 0. The game runs automatically at the current FPS.
                        

                        

                            4. Export
                            The Replay Code box updates automatically. Click Import Replay Code to load one back in.
                        

                    

                


                

                    
Keyboard Shortcuts

                    

                        

                            Q
                            Restart the TAS from frame 0.
                        

                        

                            V
                            Pause — or, if already paused, advance exactly one frame (frame-step).
                        

                        

                            B
                            Resume playback (unpause).
                        

                        

                            C
                            Step back one frame (rewind by one).
                        

                        

                            1 · 2 · 3
                            Save state to slot 1, 2, or 3 at the current frame.
                        

                        

                            4 · 5 · 6
                            Load state from slot 1, 2, or 3 (loads the frame saved with that slot).
                        

                        

                            H
                            Toggle Handplay Mode — lets you record inputs live by holding keys and pressing V.
                        

                        

                            Space
                            Pause / Unpause
                        

                    

                    
Save states are stored in memory only — they are lost on page refresh.

                


                

                    
Frame Input Syntax

                    
Each token is a set of keys followed by a frame count.
                    Keys are W (up/jump), A (left),
                    S (down), D (right).
                    They are case-insensitive.


                    

                        

                            D1
                            Hold D (right) for 1 frame.
                        

                        

                            WD5
                            Hold W + D simultaneously for 5 frames.
                        

                        

                            _6
                            No keys held for 6 frames (underscore = empty).
                        

                        

                            6
                            Also means no keys for 6 frames (number alone).
                        

                        

                            (D1 SD1)50
                            Repeat the contents of the parentheses 50 times.
                        

                        

                            break
                            Auto-pauses playback at this frame so you can inspect the state.
                        

                        

                            // comment
                            Everything after // on a line is ignored.
                        

                    


                    

                        D1 WD5  // right for 1 frame, then jump-right for 5

                        _6 W1 _3  // wait 6, jump 1, wait 3

                        (D1 _1)10  // tap D every other frame, 10 times

                        break  // pause here to check position

                        SD8  // crouch + right for 8 frames
                    


                    
The active token is highlighted in yellow in the editor as the TAS plays.

Randy (stochastic explorer)

                    

                        The Randy tab runs a random-mutation explorer instead of an exhaustive search.
                        It keeps one best route per spot on a grid and keeps spawning mutated runs from the frontier, so it can cover long
                        routes (hundreds of frames) that the Brute Force Solver cannot, at the cost of not being a proof.
                    

                    

                        Pick a goal by clicking the map (or typing X/Y, or taking the current frame's position),
                        optionally capture a start state, then press START. The map shows heat (how many frames, or replay-code characters, it
                        took to first reach each spot), the best route so far in magenta, the start in green and the goal in yellow.
                        Goal, key weights, mutate rate, step size, kill radius/zone, spawn window and caps can be changed while it runs.
                        Grid res, tile size, the optimise-for mode and the start state are read once at START.
                    

                    

                        Load into Frame Inputs replaces the editor contents with the best route.
                    

                    
Choose the search engine with the ENGINE selector next to START. (The faster native C engine is only in the full download.)

                    

                        

                            JS (full physics, workers)
                            Default. Runs in your browser on the same physics.js as the editor, so every mob and tile is simulated (lifts, crushers, saws, burthas, walkers, worms, eye launchers, pips, doors, keys, checkpoints, apples) and a route matches the editor exactly. Needs no server and no compiler. It spreads the search over several Web Workers (WORKERS, 0 = auto): each worker explores on its own, and whenever one finds a better route the others are seeded with it. The tab shows one merged result.
                        

                        

                            JS (single thread)
                            The same search on the page's main thread, in short time slices. Use it for debugging or if your browser cannot run workers (the pool falls back to it by itself).
                        

                    

                    
SET START STATE (CURRENT FRAME) captures the whole frame for the JS engine (mob positions, collected keys, opened doors), so a search can start mid-level.

                


                

                    
RNG Manipulation (eye spins & pip hops)

                    

                        Some mobs use Scratch's random(). The editor does not hide this behind a seed. Instead, each random
                        outcome you pick is saved in the replay code, so a replay always plays back the same way.
                    

                    

                        

                            Eye launchers
                            Click an eye launcher tile on the stage to open its popup. Set its spin speed (8–20°/tick) and direction (clockwise or counter-clockwise). Reset to default restores the natural 15°/tick clockwise.
                        

                        

                            Pips
                            Each pip tile has 6 bodies (the original and 5 clones). By default a pip just walks. Its popup shows the tile's survival chance, how many outcomes are saved for it, and whether it touches you with them. Tiles with saved hops are marked hops N on the stage.
                        

                        

                            Find surviving pip RNG
                            In a pip popup: searches for the hop outcomes that get your TAS past that tile and saves the cheapest ones (fewest outcomes, so the shortest replay code). It reports "no way through" only when a search that cut nothing off found none. Cancel keeps what was found so far. Reset to default forgets the tile's hops. Editing the TAS never re-rolls or re-searches hops.
                        

                        

                            Survival analysis
                            Shows how likely the TAS is to survive. Eye spins are tried exhaustively (every speed and direction), and pips follow every random outcome exactly, never a sampled estimate. On a level with eye launchers or pips it does not run by itself: press Calculate survival next to the Replay Code title. A progress bar with Cancel appears under it, and editing anything restarts the analysis.
                        

                        

                            Replay code
                            Eye spins and pip hops are stored after a ~ in the replay code, so sharing the code shares the manipulation. Old codes with rng numbers after a . still load, but those numbers are ignored.
                        

                    

                    
Randy's JS engine simulates these mobs too, so it can find routes that avoid them. The native C engine ignores eye launchers and pips entirely.

Replay Code

                    

                        The Replay Code box (Frame Inputs tab, bottom) contains the game's
                        native binary-encoded replay format.
                        It is regenerated automatically whenever your inputs change.
                    

                    

                        To load someone else's replay, paste it into the Replay Code box and click
                        Import Replay Code. This converts it back to TAS-format inputs
                        in the editor so you can inspect or modify it frame by frame.
                    

                


                

                    
Handplay Mode

                    

                        Press H to toggle Handplay Mode (status turns orange).
                        In this mode you record inputs frame-by-frame at the current playhead position —
                        works when the TAS is paused.
                    

                    

                        

                            Hold W/A/S/D
                            The keys you physically hold are shown in the Keys status field.
                        

                        

                            V (while in Handplay)
                            
                                Commits one frame with the currently-held keys, inserted at the playhead position
                                rather than appended to the end.
                                If the playhead is inside an existing token with a different combo, that token is split.
                                If the combos match, the token is simply extended by 1.
                                The playhead then advances one frame.
                            
                        

                        

                            H again
                            Exit Handplay Mode and return to normal operation.
                        

                    

                    
Tip: seek to any frame mid-sequence with the timeline, then use Handplay to overwrite or insert frames there without touching the rest of the TAS.

                


                

                    
Camera Pan

                    

                        You can freely reposition the camera at any time — including while paused or frame-stepping.
                    

                    

                        

                            Click & drag canvas
                            Pan the camera in any direction. Works during playback and while paused. Once you pan, the camera stays where you put it and no longer follows the player.
                        

                        

                            Double-click canvas
                            Same as the Recenter button (top-right of the canvas): follow the player again at the default zoom.
                        

                        

                            Mouse wheel on canvas
                            Zoom in / out around the cursor. Also unlocks the camera from the player.
                        

                    

                


                

                    
Tips & Tricks

                    

                        

                            Use break
                            Place a break token just before a tricky section. The TAS pauses automatically so you can study the player state before continuing.
                        

                        

                            Save states
                            Save (1–3) at a known-good frame, experiment with V/C to step forward/back, then reload (4–6) if things go wrong.
                        

                        

                            Lower FPS
                            Drop the FPS field to 1–5 to watch slow-motion and read each frame's state clearly.
                        

                        

                            Solver + paste
                            Pause at a tough spot, run the solver for a few frames, copy the output, and paste it into the inputs editor at that position.
                        

                        

                            Parentheses
                            Use (…)N to repeat long patterns compactly — great for corridors or repeated jumps.
